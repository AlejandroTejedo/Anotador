# Código de conducta

Este proyecto sigue el [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) ([en español](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/)).

En resumen: trata a todo el mundo con respeto, critica ideas y no personas, y ayuda a que quien llega nuevo se sienta bienvenido.

Para reportar un comportamiento inaceptable, usa el reporte privado de GitHub o contacta con el mantenedor por GitHub (@AlejandroTejedo).
